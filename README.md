## Teknologi yang Digunakan
Proyek ini dibangun menggunakan struktur *front-end* murni dengan bantuan *framework*:
* **HTML5** - Struktur utama halaman web.
* **CSS3** - Kustomisasi gaya, animasi *hover*, dan gradasi warna.
* **Bootstrap 5** - *Framework* CSS untuk memastikan tata letak yang responsif (Mobile Friendly).
* **Font Awesome** - Kumpulan ikon *vector* (untuk keahlian dan kontak).
* **Google Fonts (Poppins)** - Tipografi utama website.

## Fitur Utama
* **Responsif Penuh:** Tampilan menyesuaikan dengan baik di perangkat *mobile*, *tablet*, maupun *desktop*.
* **Navigasi Sticky:** Navbar memiliki efek transparan dan selalu berada di atas saat halaman di-scroll.
* **Smooth Scrolling:** Efek transisi halus saat mengklik menu navigasi menuju ke *section* yang dituju.
* **Desain Modern:** Menggunakan elemen UI kekinian seperti *glassmorphism* tipis pada navbar, gambar profil melingkar, dan kartu proyek yang interaktif.
